The program folder and its files

For: FullPlayer

LumiDMX Remake needs no setup program: the programs run from the folder they are in. Keep them together in one folder, for example D:\LumiDMX Remake. Each program writes its settings next to itself.

What is in the folder

FileWhat it is
LumiDMX_Remake_Full v12.exeLumiDMX Remake Full (the version is part of the name).
LumiDMX_Remake_Player.exeLumiDMX Remake Player.
LumiDMX_Remake_Help.chmThis manual. The Help button of the quick bar opens it from here.
LumiDMX_Fixture_Editor.exeThe Fixture Editor. It must be in the folder of the Full: it uses the Full's activation, and the Full opens it from Setup & Patch.
dmx_simulator_settings.jsonThe settings of the Full and of the Player, and their activation keys: the last projects, the DMX interfaces, the MIDI ports, the place of the 3D program, how the window looks. Written by the programs; you do not need to open it.
Default Project.jsonThe colours of the APC mini mk2 controller (its window Colors In-Out feedback): what colour each pad shows. See Remote, controllers and MIDI.
fixture_editor_settings.jsonThe Fixture Editor's folders (the library, the last folder opened) and its last files.

The 3D program (3D LumiDmx Remake.exe) can be in this folder or anywhere else; it keeps its own settings and key in 3D LumiDmx Remake.json next to it. The first time you press Launch 3D, the Remake asks where it is and then remembers it.

Projects and fixture profiles

Projects (.x1, .xR) can be anywhere. The fixture profiles (.lfi2) are not inside the project: the project only names them. When a project opens, the program looks for its profiles, in this order, until it has found all of them (each place with the folders inside it):

  1. in the folder chosen with Options > Fixtures folder (.lfi2), if you chose one;
  2. the profiles you chose in +New Fixture / New Fixture with "show-ready" since the program started, wherever they are;
  3. in the folder of the project;
  4. in the folder above it;
  5. in ScanLib, in the program's folder (where LumiDMX_Remake_Full.exe is - the library of the original LumiDMX, when the Remake is put in its folder, whatever that folder is called);
  6. in the whole program's folder.

Only when a profile is still missing after all of them, the program says where it looked and asks for the folder. Nothing is copied.

So the simplest way is to keep each project together with the profiles of its fixtures:

D:\Projects\Club\Club.xR
D:\Projects\Club\Beam 5R 16_Ch.lfi2
D:\Projects\Club\Blinder SMD Atomic 12_Ch.lfi2

When the profiles are kept somewhere else, choose their folder with Options > Fixtures folder (.lfi2) (the Options button of the top bar).

What to keep a copy of

  • your projects (.x1, .xR) and the profiles of their fixtures (.lfi2);
  • dmx_simulator_settings.json: your settings, and your activation (see Activation);
  • Default Project.json when you changed the colours of the controller's pads;
  • 3D LumiDmx Remake.json (the 3D's settings and key).

Moving to another computer

Copy the whole folder. The settings come along, but the activation does not: a key is made for one computer, so the programs ask for a new one on the new computer.

Note: while the program runs, it writes the patch for the 3D program into x1patch.xml in the Windows temporary folder. You do not need to keep it.
