The programs

For: FullPlayer

LumiDMX Remake comes as four programs. The two main ones, Full and Player, look the same and play the same projects; the Player cannot change them.

ProgramIts fileWhat it does
LumiDMX Remake Full
Full		 LumiDMX_Remake_Full v12.exe
(the version is part of the name)		 Plays and changes projects: the fixtures and their addresses (+Add Fixture), the Live panel (Design Live-Panel), the Effect Generator, shows, Sound2Light, the 2D View, macros. Opens .x1 and .xR projects, saves .xR.
LumiDMX Remake Player
Player		 LumiDMX_Remake_Player.exe Plays projects as they are. The tools that change the patch and the Live panel are not in this program: Design Live-Panel, the Effect Generator and +Add Fixture show Modify here not available. Opens .x1 projects.
3D LumiDmx Remake 3D LumiDmx Remake.exe Shows the fixtures of the patch in 3D, with the light the Remake sends: beams, colours, gobos, movements. Started from the Remake with Launch 3D. See 3D Previsualisation.
LumiDMX Fixture Editor
Full		 LumiDMX_Fixture_Editor.exe Makes and changes the fixture profiles (.lfi2); makes them from the DMX table of a manual or from QLC+, Open Fixture Library and GDTF files; finds the profiles of the library with the same channels. See LumiDMX Fixture Editor.

Full and Player

  • With the Full the projects are built and kept up to date: the patch, the buttons of the Live panel, the effects, the shows.
  • With the Player a finished project is played: in a club, by a DJ, at an event. Nothing of the project can be broken by mistake, because the tools that change it are not there.

Both open with the same window and the same project; the pages of this help say with the badges Full Player which of them has what the page describes.

.x1 and .xR

A project is one file. .x1 is the project file of LumiDMX X1; the Full and the Player open it. The Full saves its projects as .xR: a file that only LumiDMX Remake Full opens. More in Opening and saving a project.

Activation

Each program is activated for the computer it runs on; the Full, the Player and the 3D each have their own key. The Fixture Editor uses the activation of the Full. See Activation.
