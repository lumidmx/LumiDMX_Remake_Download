Commands

For: FullPlayer

The list of the commands that help shows on the Command Line: all the commands of LumiDMX Remake, in the same groups. The commands work the same in a button's On Start / On Stop, in a slider's commands, in a macro and on the Command Line. Where the commands are written: Macros and the Command Line.

Names in the commands

In every command a name - of an object, a sequence, a slider, a macro or a variable - is found whatever its capital letters and extra blanks: Blue Wash, blue   wash and BLUE WASH are the same name. A blank between two words counts: BlueWash is another name.

Mixer commands

CommandWhat it does
SetallSets every channel of the current universe to 100%.
ResetAllSets every channel to 0% - never touches OUT / MAN / IN or stops a running button, only values.
U(Universe)Sets the mixer's current universe (1-16): the one the channel commands work on.
SetDMX(Channel, Value)Sets one DMX channel to a value (0-255).
(1-5+8) = ValueSets several channels at once - here the channels 1 to 5 and 8.
PushleftShifts every value left by one channel.
PushrightShifts every value right by one channel.
setChMode(Channel, Mode)Sets a channel's mode: man, in, out.
setChModeAll(Mode)Sets every channel's mode: man, in, out.
setChMixMode(Channel, Mode)Sets a channel's mix mode, as the Mixer's settings do: ltp, htp (the highest value wins), mixed (the average of the values).
setOffset(Univ, Ch, Slider)Adds the slider's value to a channel's output.
fixtureSwapXY(Univ, StartAdr)Swaps a fixture's X / Y (Pan / Tilt).
fixtureInvertPan(Univ, Adr)Inverts a fixture's Pan channel.
fixtureInvertTilt(Univ, Adr)Inverts a fixture's Tilt channel.
setVolume(0..100)Sets Windows' master volume: 100 = maximum, 50 = half. In a slider's On Change Command, setVolume(its own name) moves the volume with the slider (the slider's range 0..100).
randomPuts random values on the mixer.
blackoutTurns Blackout on / off (the output only, as Freeze - the programmed and live values underneath are not touched).
freezeTurns Freeze on / off.
incdmx(Channel, Value)Increments a DMX value.
decdmx(Channel, Value)Decrements a DMX value.

Live-Panel commands

CommandWhat it does
runObject(Name)Starts an object by its name: a button / sequence, or a Show button by its show's name.
stopObject(Name)Stops an object by its name.
stopAllObjectsStops every object on the panel.
setSeqSpeed(Name, Value)Sets a sequence's speed: 100 = its normal speed, less = slower, more (up to 255) = faster.
seqBlackout(Name)Turns one sequence's own Blackout on / off.
setLivePageIndex(Index)Switches the page shown (0 = the first page).
setSlider(Slider, Value)Sets a slider to a value.

Pan / Tilt Size commands

CommandWhat it does
setSizePan(Value)Makes the Pan movements of the fixtures ticked in Pan / Tilt Size bigger or smaller round their own centre: -100 = held at the centre, -50 = half, 0 = as programmed, +100 = twice as big.
setSizeTilt(Value)The same for the Tilt movements.
setSizePT(Value)Adds the same value to Pan and Tilt (the P+T row): they keep their difference; setSizePT(0) gives them back their own values.

The value can be a slider's name: its value (for example a slider from -100 to 100 with the On Change Command setSizePan(its own name)). The commands set the rows as the MIDI faders do; right click the box in the top bar for its settings.

Windows commands

CommandWhat it does
showMixer / hideMixerShows / hides the General Mixer.
showFixtures / hideFixturesShows / hides Fixture Control.
showDMXBoard / hideDMXBoardShows / hides the DMX Board.
showCmd / hideCmdShows / hides the Command Line.
showfrm(frmtimer)Shows the Timer and ticks Time code in Monitor settings.
showfrm(frmdmxvis)Shows the DMX Visualizer and ticks DMX Visualizer in Monitor settings.
showfrm(frmstageview)Shows Stage View and ticks Stage View in Monitor settings (see Stage View).
showAudioMixer / hideAudioMixerOpens / closes the Windows Volume Mixer.
lockLivePanel / unlockLivePanelLocks the Live-panel, as its Lock Live-panel button (only the pages and the panel, full screen) / unlocks it, as Esc.
MacroOpens the Macro Editor.

Macros commands

CommandWhat it does
a macro's nameRuns that macro.
wait(ms)Waits that many milliseconds before the macro's next line.
loop(4) ... endloopRuns the lines between them 4 times (loops inside loops too; loop(0) skips them).
var(MyVar, Value)Keeps a whole number under a name.
inc(MyVar) / inc(MyVar, 2)Adds 1 (or 2) to it.
dec(MyVar) / dec(MyVar, 2)Takes 1 (or 2) from it.

wait, loop and endloop work only inside a macro. A variable's name can stand for a number in any command: setDMX(MyVar, 255), wait(MyVar), loop(MyVar), setSlider(Dim, MyVar). Variables work alike in macros, buttons, sliders and on the Command Line, and are kept until a project is opened.
