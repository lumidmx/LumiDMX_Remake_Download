What is saved

For: FullPlayer

Everything you set on the Sound2Light tab belongs to the project and is written into its S2L.dat when the project is saved:

  • the BPM lists (their chases, in their order) and the Fade of each list;
  • the squares: their place, size, name, the list each one steps, the Beat and Dir. Trigger squares and the Beat threshold;
  • the EQ sliders and the EQ presets.

The copies of the chases of the lists are in the project too (the Library's BPM List folder). The project asks to be saved after a change.

The Player plays Sound2Light the same way, and its Save writes S2L.dat: lists, squares and EQ can be set and kept there too.

With the rest of the program

  • Step Direction (main bar, remote, Dir. Trigger) turns the Move List backwards.
  • The remote player (Back, Play, Forward) and the Live panel keep working while Sound2Light plays; the last one started takes the channels (LTP).
  • Rec ON / Rec OFF is also in the Monitor window.
