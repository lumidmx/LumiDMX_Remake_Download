LumiDMX Fixture Editor

For: Full

Every fixture of a project needs its profile: a .lfi2 file that says what each of its DMX channels does (see DMX in a few words). The LumiDMX Fixture Editor makes new profiles and corrects existing ones. It works like the fixture editor of LumiDMX X1 (ScanEdit) and writes the same files, so a profile made here is read by LumiDMX X1 too. It also opens the older .lfi profiles.

What it adds:

  • Import - a profile made from the DMX table of the fixture's manual (copied and pasted), or from a QLC+, Open Fixture Library or GDTF file;
  • Check against the library - the profiles of your library with the same channels, or nearly the same, compared channel by channel;
  • Export - a report, an HTML page, a PDF, the pictures or a JSON file of the profile;
  • safety: Test runs before every save, and a profile with problems is not saved; every change is marked not saved!; Save As asks before it writes over another file.

Opening the editor

  • From LumiDMX Remake Full: Setup & Patch > +Add Fixture > Library tools > LumiDMX Fixture Editor (.lfi2 editor) (see Library tools).
  • From Fixture Filter (the library browser of the same menu): right click on a result > Open in Fixture Editor. The profile opens with Save grey: save it with Save Fixture As... first, so that the file of the library is not changed by mistake (Ctrl+S does Save As then).
  • On its own: LumiDMX_Fixture_Editor.exe in the program folder. A .lfi2 file dropped on its window opens; a QLC+, Open Fixture Library or GDTF file dropped on it is imported.

Important: the editor opens only where LumiDMX Remake Full is activated: it must be in the same folder as the Full (it reads the Full's dmx_simulator_settings.json). Otherwise it says Please register LumiDMX Remake.
