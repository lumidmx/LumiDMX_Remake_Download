Files and settings

For: Full

The profiles

File
.lfi2The profiles of LumiDMX Remake and LumiDMX X1. The editor opens and saves them. Everything is inside the file: the data, the channels, the presets and all the pictures. Only the gobo files of High Res. Gobo are named, not included.
.lfiThe older profiles. The editor opens them and saves them as .lfi2.

The editor's settings

The editor keeps its own settings in fixture_editor_settings.json, next to LumiDMX_Fixture_Editor.exe. They are only conveniences: when the file is missing or cannot be written, the editor works the same and starts from the program folder.

SettingWhat it remembers
library_dirthe library folder (Library > Library folder...)
open_dirthe folder of the last profile opened
import_dirthe folder of the last file imported
export_dirthe folder of the last export
picture_dir, gobo_dirthe folders of the last picture and the last gobo chosen
recent_filesthe last 8 profiles opened or saved (File > Recent Fixtures)

The activation is not here: the editor reads the Full's dmx_simulator_settings.json in the same folder (see Activation).

Starting the editor with a profile

CommandWhat it does
LumiDMX_Fixture_Editor.exe "D:\Fixtures\MH-X25 12_Ch.lfi2"opens the profile (the same as dropping it on the editor, or opening a .lfi2 with the editor from Explorer)
LumiDMX_Fixture_Editor.exe /fromfilter "D:\Fixtures\MH-X25 12_Ch.lfi2"opens it as Fixture Filter does: Save grey until a Save Fixture As...
